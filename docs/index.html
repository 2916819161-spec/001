适用范围

本政策适用于由刘春宇开发并运营的《短剧末日求生模拟器》安卓离线版，包括横屏版和竖屏版，依据版本 1.0.28 的实际功能制定。以下简称“本游戏”或“我们”。本政策说明您游玩本游戏、管理本地存档，以及通过电子邮件联系我们时的信息处理方式。

本游戏的核心玩法无需注册、登录或联网。不适用本政策的网页版试玩、应用商店、电子邮件服务及您自行选用的云盘等第三方服务，其信息处理规则由相应服务提供者另行说明。

在设备本地处理的信息

为了保存进度与提供正常游戏体验，本游戏会在应用私有空间中保存游戏进度、剧情选择、物资状态、保存时间、自动存档、手动存档及其备份，以及画质、音量、文字大小和旁白等偏好和开场提示的已阅状态。这些数据不用于识别您的现实身份，不会由当前离线版本上传给我们。

为了选择合适的画质与操作方式，本游戏会在本机读取并使用低内存标志、内存等级及总量、设备类型、触控能力、屏幕和视口尺寸、像素密度及图形能力等运行信息。该处理用于性能适配，不用于广告画像或跨应用追踪，未设置向我们上传这些信息的功能。

运行错误可能记录在设备的本地系统日志中。本游戏没有自动上传崩溃日志、游戏行为或性能数据的功能。

权限与不会主动收集的信息

当前安卓离线安装包未声明 Android 系统权限，包括未申请互联网访问、定位、相机、麦克风、通讯录、短信、电话以及广泛文件存储权限。游戏不主动读取您的真实姓名、手机号码、身份证件、精确位置、通讯录、相册、IMEI、IMSI 或广告标识符，也不扫描您的其他应用或个人文件。

游戏中的旁白和人物语音通过安装包内的音频文件播放，不进行录音、语音识别或向云端提交对话内容。游戏中的虚构人物、对话与角色信息不代表收集您的真实身份信息。

存档导入与导出

仅当您主动选择导入或导出存档时，游戏才会调用 Android 系统文档选择器，读取您选中的 JSON 存档文件或向您指定的位置写入 JSON 备份。单次导入文件的大小上限为 4 MB；该操作不授予游戏扫描全部文件的能力。

导出文件可能包含游戏进度、游戏选择、资源状态和保存时间。请自行保管，避免分享您不希望他人看到的存档内容。如果您在系统选择器中选择云盘或其他文件服务，相关文件同步由该服务提供者处理，不是本游戏主动向我们上传存档。

第三方组件与信息提供

本游戏使用 Android 系统 WebView 和随安装包提供的本地渲染、界面及音频等基础组件。当前版本未接入账号登录、广告、支付、统计、推送或崩溃上传 SDK，未设置由这些组件向我们或其他主体上传玩家数据的功能。

我们不会出售、出租或主动公开您的本地游戏数据，也没有通过本游戏向境外传输这些数据的功能。您主动导出、分享存档或通过邮件发送的资料，按您选择的操作及相关服务的规则处理。

主动联系我们时的信息

如果您向隐私联系邮箱发送问题或反馈，我们会收到您主动提供的邮箱地址、邮件内容，以及您自行附带的截图、存档或其他资料。我们仅在核实问题、回复请求和履行必要义务的范围内使用这些资料，不将其用于广告画像。

请勿发送与问题无关的身份证件、密码、完整个人文件等敏感信息。我们会限制资料的使用范围，并在处理请求及必要保存期限结束后删除不再需要的信息。您可以通过同一邮箱提出查询、更正或删除请求。

保存、安全与删除

应用内存档和设置保存在当前设备的应用私有空间；当前安卓包关闭了应用自动备份配置。应用内数据持续保留在本机；覆盖手动存档时可能保留上一份作为恢复备份。通过系统清除应用数据或卸载应用，可删除应用内数据。我们无法从服务器恢复已被删除且没有自行备份的本地存档。

您可在 Android“设置 → 应用 → 短剧末日求生模拟器 → 存储”中清除应用数据；具体名称以您的手机系统为准。卸载应用也会删除其应用内数据。开始新旅程不等同于删除所有手动存档。

导出到应用外的 JSON 备份不会随清除应用数据或卸载而自动删除，请您到所选保存位置或相应云盘中自行删除。横屏与竖屏版本使用各自的应用数据空间时，需要分别管理。

我们通过离线运行、限制资源访问和应用私有存储等措施减少数据暴露。请妥善保管设备及备份，并使用可信来源提供的安装包。

您的选择与权利

您可以在游戏设置中调整画质、音量、文字大小和旁白等偏好，自行管理存档，并按上文方式删除本地数据。由于本游戏没有账号系统，无需办理游戏账号注销。您可以停止使用或卸载本游戏。

如果您对信息处理有疑问，或希望查询、更正、复制、删除您主动向我们提供的资料，请通过本政策所列邮箱联系。我们将在核实处理请求所需的必要信息后，依法答复和处理。我们不会要求您提供与请求无关的身份材料。

未成年人保护

未成年人应在监护人的指导下阅读本政策，并结合游戏内容与应用商店标示的适龄信息决定是否使用。本游戏不主动收集未成年人的姓名、年龄、证件或联系方式。

若监护人发现儿童在未经监护人同意的情况下，通过邮件等方式向我们提供了个人信息，可联系隐私邮箱。我们核实后会依法处理相关信息及删除请求。

访问本政策网页

本政策正文页面不设置登录、信息填写表单、广告或分析统计脚本，不读取您的游戏存档。您使用浏览器访问网页时，为传输页面及维持网络服务，浏览器、网页托管或网络服务提供者可能处理 IP 地址、请求时间、浏览器请求信息等必要的网络访问信息；其处理受相应服务提供者的规则约束。这与离线游戏主动上传数据是不同的情形。

政策更新与联系方式

如果后续版本的信息处理方式发生变化，我们会更新本政策并通过适当方式提示；涉及依法需要征得同意的处理时，会在处理前履行相应告知和同意程序。本政策的更新日期与生效日期见页首。
